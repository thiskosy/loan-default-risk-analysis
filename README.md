# Loan Default Risk — Exploratory Data Analysis

## Overview
Analyzed consumer and loan attributes to identify key drivers of loan 
repayment difficulties using real financial data.

## Business Problem
Which customer and loan attributes predict likelihood of default?

## Key Analyses
- DTI ratio impact on repayment difficulties for top 5% earners
- Education level correlation with loan repayment behaviour
- Hypothesis testing to validate findings

## Visualizations
Boxplots, violin plots, scatter plots, histograms, correlation heatmaps

## Tools
Python · Pandas · Seaborn · Matplotlib
